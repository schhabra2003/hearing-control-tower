Key details
- Texas: agents can request up to 20 properties heard consecutively on one day (§41.66(j)); notices go to agent only once designation on file (34 TAC §9.3044).
- Volume: Harris CAD 516,205 protests (2024), 376,058 settled without office visit. Cook BOR ~248,000 appeals / 411,513 parcels (TY2023), only 10,390 hearings requested (~4%). NYC TC 57,304 applications (2024), 6,722 offers accepted.
- Within-state variation: Bexar portal/CSV; Tarrant Excel upload, agent forms one PDF each, 5-10 business days processing; Travis portal self-scheduling, virtual only.
- Change frequency: Cook Assessor publishes new rules yearly; Harris ARB adopts new procedures yearly; NYC ended email bulk submissions in 2026; Florida amending 12D-9 in 2025-26.
- No public APIs found anywhere: connectors = email, portal uploads (CSV/Excel), scraping, mail.
